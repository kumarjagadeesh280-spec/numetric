Write, Preview, Publish

Compose posts here, preview them live on the site, then export the JSON and commit it. No backend, no database.

How publishing works. This is a static site, so the browser cannot write to a file on the server. Drafts you save stay in this browser only — useful for previewing, invisible to everyone else. To publish for real:
  1. Write the post and Save draft.
  2. Open the Export panel and click Download blogs.json.
  3. Replace data/blogs.json in the repo with that file and commit.
  4. Once deployed, use Clear local drafts — the post is now live for everyone.
